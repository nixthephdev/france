# Homepage direction

The current visual contract is [The framed editorial portrait](taupe-direction.md), explicitly chosen by the user with “lets build that instead bro” after supplying the Hameed eyewear reference.

The opening uses a rounded ink frame, porcelain canvas, taupe backdrop, a transparent photographic portrait, large outline lettering and a floating white featured-insight panel. It replaces the previous Oviron-style forest/citron hero and story strip. Earlier directions remain in Git history, not as current implementation authority.

Reading insights remains the primary action. About, Speaking, Projects and Contact remain actual pages; supplied profile roles, professional experience, email and LinkedIn content are preserved. The current system is documented in DESIGN.md and its sidecar after implementation and review.
